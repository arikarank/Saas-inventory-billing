# SAAS Inventory & Billing System

A comprehensive inventory management and billing system for small businesses built with Python Flask.

## Features

- 📦 Product Management with stock tracking
- 👥 Customer Management
- 🧾 Invoice Generation
- 📊 Dashboard with analytics
- 📈 Low stock alerts
- 📁 Import/Export functionality
- 👤 User authentication
- 💳 Subscription management
